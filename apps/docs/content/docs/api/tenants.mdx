# Tenants API

---

## Public (no auth required)

### POST /tenants/register

Create a new workspace. This is the self-service onboarding endpoint.

```http
POST /tenants/register
Content-Type: application/json

{
  "workspaceName": "Acme Corp",
  "slug": "acme",
  "adminName": "Ada Lovelace",
  "adminEmail": "admin@acme.com",
  "adminPassword": "StrongPass123!"
}
```

**Response `201`:**

```json
{
  "accessToken": "eyJ...",
  "refreshToken": "...",
  "tenantSlug": "acme",
  "user": {
    "id": "uuid",
    "email": "admin@acme.com",
    "name": "Ada Lovelace"
  }
}
```

**Errors:** `409` slug taken · `400` invalid slug (reserved word, too short, invalid chars) · `429` rate limited (3/hour/IP)

Slug rules: 4–63 characters, lowercase letters/numbers/hyphens only, no reserved words (`sentry`, `www`, `api`, `admin`, etc.)

---

### GET /tenants/slug-check

Check whether a workspace slug is available. Used for real-time availability validation in the onboarding wizard.

```http
GET /tenants/slug-check?slug=acme
```

**Response `200`:**

```json
{ "available": true }
```

```json
{ "available": false, "reason": "This slug is taken" }
```

Rate limited: 30 requests / minute / IP.

## Authenticated

### GET /tenants/current

Get the current tenant's settings.

```http
GET /tenants/current
Authorization: Bearer <access-token>
x-tenant-id: acme
```

**Response `200`:**

```json
{
  "id": "tenant-uuid",
  "slug": "acme",
  "name": "Acme Corp",
  "plan": "free",
  "status": "active",
  "allowedOrigins": "https://app.acme.com",
  "customDomain": null,
  "createdAt": "..."
}
```

---

### PATCH /tenants/current

Update tenant settings. Requires `settings:write` permission.

```http
PATCH /tenants/current
Authorization: Bearer <admin-token>
Content-Type: application/json

{
  "name": "Acme Corporation",
  "allowedOrigins": "https://app.acme.com,https://app2.acme.com"
}
```

---

### GET /tenants/current/password-policy

Get the tenant's effective password and lockout policy. Tenants that never configured one get
the platform defaults. Requires `tenant:read`.

```http
GET /tenants/current/password-policy
Authorization: Bearer <admin-token>
```

**Response `200`:**

```json
{
  "minLength": 12,
  "requireCommonPasswordCheck": true,
  "historyCount": 5,
  "maxAgeDays": 0,
  "lockoutThreshold": 5,
  "lockoutDurationMinutes": 15
}
```

---

### PUT /tenants/current/password-policy

Set any of the fields below (omitted fields keep their current value). Requires `tenant:write`;
the change is audited as `tenant.settings_updated`.

| Field | Range | Effect |
|---|---|---|
| `minLength` | 12-128 | Minimum password length. A tenant can only be stricter than the platform minimum of 12. |
| `requireCommonPasswordCheck` | boolean | Reject passwords on the common-password deny list. |
| `historyCount` | 0-24 | Previous passwords that cannot be reused. |
| `maxAgeDays` | 0-3650 | Days before a password expires; `0` means never. An expired password is refused at sign-in with `AUTH_PASSWORD_EXPIRED` (403) until it is reset. |
| `lockoutThreshold` | 3-20 | Failed sign-ins before the account locks. |
| `lockoutDurationMinutes` | 1-1440 | How long a locked account stays locked. |

```http
PUT /tenants/current/password-policy
Authorization: Bearer <admin-token>
Content-Type: application/json

{ "minLength": 16, "historyCount": 10, "maxAgeDays": 90 }
```

**Response `200`:** the full effective policy (same shape as `GET`). Values outside the ranges
answer `422`.

The policy applies to registration, invite acceptance, password reset and password change.
