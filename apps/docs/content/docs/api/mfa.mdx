# MFA API

---

## POST /api/mfa/totp/setup

Begin TOTP enrollment. Returns a secret and QR code to scan.

```http
POST /api/mfa/totp/setup
Authorization: Bearer <access-token>
```

**Response `200`:**

```json
{
  "secret": "JBSWY3DPEHPK3PXP",
  "qrCode": "data:image/png;base64,...",
  "backupCodes": [
    "ABCD-1234", "EFGH-5678", "IJKL-9012",
    "MNOP-3456", "QRST-7890", "UVWX-1234",
    "YZAB-5678", "CDEF-9012", "GHIJ-3456", "KLMN-7890"
  ]
}
```

---

## POST /api/mfa/totp/verify

Confirm TOTP enrollment with a valid code from the authenticator app.

```http
POST /api/mfa/totp/verify
Authorization: Bearer <access-token>
Content-Type: application/json

{
  "code": "123456"
}
```

**Response `200`:** MFA enabled on the account.

## POST /api/auth/mfa/verify

Complete login after a response with `mfaRequired: true` (`tempToken`, `availableMethods`).
Only methods the user has actually enrolled are advertised and accepted.

```http
POST /api/auth/mfa/verify
Content-Type: application/json

{ "tempToken": "<tempToken>", "method": "totp", "code": "123456" }
```

| `method` | Needs |
|---|---|
| `totp` (default) | `code` |
| `email` | `code` from `POST /api/auth/mfa/request-email-otp { tempToken }` (200, rate limited) |
| `webauthn` | `webauthnResponse` + `sessionNonce` from `POST /api/auth/mfa/webauthn/start { tempToken }` |

Backup codes use `POST /api/auth/mfa/verify-backup { tempToken, code }`. Session cookies are set; the
body has `{ message, tenantSlug, session, expiresIn }`. The session `amr` reflects the first factor
plus the second one (for example `["pwd","otp","totp","mfa"]`).

## Pre-session enrollment (policy requires MFA)

When login / magic link / passkey answers `{ "status": "mfa_enrollment_required" }`, the enrollment
token is in the body (password login) or the `mfa_enrollment_token` cookie. It is valid 15 minutes,
bound to the tenant and user, single use, and burned after 5 wrong codes. Pass it as
`enrollmentToken` in the body or rely on the cookie.

- `POST /api/auth/mfa/enroll/totp/setup { enrollmentToken? }` returns `{ secret, qrCode }`.
- `POST /api/auth/mfa/enroll/totp/confirm { enrollmentToken?, code }` enables TOTP, sets the session
  cookies and returns `{ backupCodes, tenantSlug, session, expiresIn }` (show the codes once).

## Step-up: POST /api/auth/reauth

Authenticated. Re-prove the account and refresh `authTime` of the SAME session so
`ACCESS_RECENT_AUTH_REQUIRED` endpoints pass again; the access-token cookie is reissued and the
step-up survives token refresh.

```http
POST /api/auth/reauth
{ "method": "password", "password": "..." }
{ "method": "totp", "code": "123456" }
{ "method": "webauthn", "webauthnResponse": { }, "sessionNonce": "..." }   // options: POST /api/auth/reauth/webauthn/start
```

**Response `200`:** `{ session, expiresIn }`. Wrong credentials answer `401`.

## GET /api/mfa/backup-codes

List remaining backup codes (shows which have been used).

```http
GET /api/mfa/backup-codes
Authorization: Bearer <access-token>
```

**Response `200`:**

```json
{
  "codes": [
    { "code": "ABCD-1234", "used": false },
    { "code": "EFGH-5678", "used": true }
  ]
}
```

---

## POST /api/mfa/backup-codes/regenerate

Regenerate all backup codes. All existing codes are immediately invalidated.

```http
POST /api/mfa/backup-codes/regenerate
Authorization: Bearer <access-token>
```

**Response `200`:**

```json
{
  "codes": ["ABCD-1234", "EFGH-5678", ...]
}
```

---

## DELETE /api/mfa/totp

Disable TOTP MFA. Requires current password confirmation.

```http
DELETE /api/mfa/totp
Authorization: Bearer <access-token>
Content-Type: application/json

{
  "password": "current-password"
}
```

**Response `204`:** TOTP disabled.
