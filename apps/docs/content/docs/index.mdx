# Scrolloop Sentry

Scrolloop Sentry is an enterprise-grade authentication and authorization platform built for teams that need Auth0-level capabilities with full data ownership.

## What it provides

- **Multi-tenant architecture** — schema-level isolation per workspace (`fk_{slug}` PostgreSQL schemas) with defense-in-depth row filtering
- **AWS IAM-level RBAC** — roles, permissions, groups, and a full Deny/Allow policy engine with conditions
- **MFA** — TOTP, WebAuthn/passkeys, backup codes, magic links
- **Social login** — Google, GitHub, Microsoft OAuth2 via Passport.js
- **RS256 JWTs** — per-tenant RSA key pairs, real JWKS endpoint, refresh token rotation with reuse detection
- **Full OAuth 2.0 / OIDC** — Authorization Code + PKCE, Client Credentials, token introspection, discovery
- **Self-service onboarding** — tenants register themselves at `/onboarding`
- **SDKs** — TypeScript, React, Next.js, Node.js, Vue, Angular, Go, Python, Ruby, Rust, Nginx
