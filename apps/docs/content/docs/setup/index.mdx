# Quickstart

## Prerequisites

- Node.js 20+
- Docker + Docker Compose
- Yarn 4 (`corepack enable`)

## 1. Clone and install

```bash
git clone https://github.com/rishitshivesh/my-auth.git scrolloop-sentry
cd scrolloop-sentry
yarn install
```

## 2. Configure environment

```bash
cp apps/auth-service/.env.example apps/auth-service/.env
```

Open `apps/auth-service/.env` and fill in at minimum:

```env
DATABASE_HOST=localhost
DATABASE_PORT=5432
DATABASE_USER=postgres
DATABASE_PASSWORD=postgres
DATABASE_NAME=scrolloop_sentry

REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=password

MASTER_ENCRYPTION_KEY=<run: openssl rand -base64 32>
SESSION_SECRET=<run: openssl rand -base64 32>
GDPR_IP_SALT=<run: openssl rand -base64 32>

CORS_ORIGINS=http://localhost:3000
ADMIN_PORTAL_ORIGIN=http://localhost:3000
```

See [Environment Variables](/docs/setup/env) for the full reference.

## 3. Start the local stack

```bash
docker-compose up -d
```

This starts PostgreSQL, Redis, and Mailhog (SMTP catcher at `http://localhost:8025`).

## 4. Run database migrations

```bash
cd apps/auth-service
yarn migration:run
```

## 5. Start the services

```bash
# From the repo root — starts both services in parallel
yarn dev
```

- **auth-service** → `http://localhost:4000`
- **admin-portal** → `http://localhost:3000`
- **API docs (Swagger)** → `http://localhost:4000/api-docs`
- **These docs** → `http://localhost:3001`

## 6. Complete first-run setup

On a clean database, visiting `http://localhost:3000` redirects to `/setup`.

1. **Get your setup token** — it was written to `~/.sentry/setup.log` at startup:
   ```bash
   cat ~/.sentry/setup.log
   ```
2. Enter the token in the wizard
3. Name your platform (optional)
4. Create the superadmin account
5. Click **Go to Login** — you're ready

The setup token is single-use and invalidated immediately after the admin account is created.

## 7. Create your first tenant workspace

After logging in as superadmin, or by visiting `http://localhost:3000/onboarding`:

1. Enter a workspace name (e.g. "Acme Corp")
2. Choose a subdomain (e.g. `acme`) — availability is checked in real-time
3. Create the workspace admin account
4. Your workspace dashboard is at `/t/acme/dashboard`
