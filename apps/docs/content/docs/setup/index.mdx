# Quickstart

## Prerequisites

- Node.js 20 (`.nvmrc`)
- Yarn 4 via Corepack (`corepack enable`)
- Docker (for Postgres, Redis and Mailpit)

## 1. Install and start dependencies

```bash
yarn install
docker compose up -d   # Postgres 16, Redis 7, Mailpit (http://localhost:8025)
```

## 2. Configure

```bash
cp apps/auth-service/.env.example apps/auth-service/.env
```

Fill in the four secrets (the generation command for each is in the file):

```env
JWT_SECRET=            # openssl rand -hex 32
SESSION_SECRET=        # openssl rand -hex 32
KEYRING_MASTER_KEY=    # openssl rand -base64 32
TOKEN_ENCRYPTION_KEY=  # openssl rand -hex 32
```

The defaults already point at the Docker services. See
[Environment Variables](/docs/setup/env) for everything else.

## 3. Migrate and seed

```bash
cd apps/auth-service
yarn db:migrate
yarn db:seed
```

## 4. Run

```bash
yarn dev                                # auth-service → http://localhost:4000
yarn dev --filter=admin-portal          # from repo root → http://localhost:3000
```

On first boot the auth-service prints `FIRST RUN SETUP TOKEN: …`. Open
`http://localhost:3000/setup`, paste it, and create the first superadmin.

## 5. Verify

```bash
curl localhost:4000/health/ready
curl localhost:4000/.well-known/openid-configuration
```

Swagger (development only): `http://localhost:4000/api-docs`.
