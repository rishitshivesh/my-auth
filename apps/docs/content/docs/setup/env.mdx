# Environment Variables

All configuration is read from environment variables. Copy `.env.example` to `.env` and fill in the required values.

Generate secrets with: `openssl rand -base64 32`

---

## Database

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `DATABASE_HOST` | ✅ | — | PostgreSQL host |
| `DATABASE_PORT` | ✅ | `5432` | PostgreSQL port |
| `DATABASE_USER` | ✅ | — | PostgreSQL username |
| `DATABASE_PASSWORD` | ✅ | — | PostgreSQL password |
| `DATABASE_NAME` | ✅ | — | Database name |
| `DATABASE_LOGGING` | — | `false` | Enable TypeORM query logging |
| `DB_SSL` | — | `false` | Enable SSL for DB connection |

---

## Redis

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `REDIS_HOST` | ✅ | `localhost` | Redis host |
| `REDIS_PORT` | ✅ | `6379` | Redis port |
| `REDIS_PASSWORD` | — | — | Redis AUTH password |

---

## Security

| Variable | Required | Description |
|----------|----------|-------------|
| `MASTER_ENCRYPTION_KEY` | ✅ | AES-256-GCM key for OAuth token encryption. Must be 32+ random bytes, base64-encoded. |
| `SESSION_SECRET` | ✅ | Express session secret. Must be 32+ random bytes, base64-encoded. |
| `GDPR_IP_SALT` | ✅ | HMAC salt for IP address anonymization in audit logs. |

---

## CORS

| Variable | Required | Description |
|----------|----------|-------------|
| `CORS_ORIGINS` | ✅ | Comma-separated list of allowed origins. Example: `http://localhost:3000,https://admin.acme.com` |
| `ADMIN_PORTAL_ORIGIN` | — | Explicit admin portal URL. Added to the bootstrap CORS allowlist so the setup wizard can reach the API before any tenant is configured. |

---

## SMTP

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `SMTP_HOST` | ✅ | — | SMTP server hostname |
| `SMTP_PORT` | ✅ | `587` | SMTP port |
| `SMTP_USER` | — | — | SMTP username |
| `SMTP_PASS` | — | — | SMTP password |
| `SMTP_FROM` | — | — | Sender address for transactional emails |
| `SMTP_SECURE` | — | `false` | Use TLS (port 465) |

For local development, Docker Compose starts [Mailhog](http://localhost:8025) on port 1025.

---

## URLs

| Variable | Required | Description |
|----------|----------|-------------|
| `FORT_KNOX_BASE_URL` | ✅ | Internal URL for the security/encryption microservice |
| `NEXT_PUBLIC_AUTH_SERVICE_URL` | ✅ | Public URL of the auth-service (used by the admin portal). Example: `http://localhost:4000` |
| `NEXT_PUBLIC_ROOT_DOMAIN` | — | Root domain for subdomain-based tenant routing. Example: `sentry.scrolloop.com`. Defaults to that value. |

---

## Setup

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `SENTRY_SETUP_LOG_DIR` | — | `~/.sentry` | Directory where the first-run setup token is written to `setup.log` |

---

## Application

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `PORT` | — | `4000` | HTTP port for auth-service |
| `NODE_ENV` | — | `development` | `development` or `production`. CSP headers and Swagger are disabled in production. |
