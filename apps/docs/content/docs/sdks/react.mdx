# React SDK

Included in `@scrolloop/sdk/react` (re-exported from `@scrolloop/sdk`). The provider holds the current user and
exposes the client; hooks expose the typed modules of [the TypeScript SDK](/docs/sdks/typescript).

## Setup: a client per tenant, never a singleton

```tsx
"use client";
import { SentryProvider, useCreateSentryClient } from "@scrolloop/sdk/react";

export function Providers({ tenant, children }: { tenant: string; children: React.ReactNode }) {
  const client = useCreateSentryClient({ baseURL: process.env.NEXT_PUBLIC_AUTH_URL!, tenant });
  return <SentryProvider client={client}>{children}</SentryProvider>;
}
```

`useCreateSentryClient` memoises by `baseURL` and `tenant`, so navigating to another tenant's subdomain builds a new client.

## Auth state

```tsx
const { user, isLoading, isAuthenticated, error, login, logout } = useAuth();
const { user } = useUser();
const { session } = useSession(); // non-secret claims: tenantId, tenantSlug, groups
```

`login`, `verifyMagicLink`, `finishPasskeyLogin` and `authenticateWithPasskey` resolve with the full `AuthOutcome`;
the provider loads the user only when a session was actually established, so MFA challenge and enrollment
branches are yours to render.

## Module hooks

Each returns the matching client module (stable reference):

`useSignIn()`, `useAccount()`, `useMfa()`, `usePasskeys()`, `useSessions()`, `useInvites()`, `useConsent()`, `useSocial()`, `useTenantApi()`, and `useSentryClient()` for the client itself.

## Pending and error state

`useSentryAction` wraps any SDK call. `run` rethrows, so typed errors still reach your handler, and `data`
is only set after the server confirmed success:

```tsx
const accountApi = useAccount();
const resend = useSentryAction(accountApi.resendVerification);

<button disabled={resend.isPending} onClick={() => resend.run(email).catch(() => {})}>Resend</button>
{resend.error && <p role="alert">{resend.error.message}</p>}
```

## Recent authentication

```tsx
const account = useAccount();
const recent = useRecentAuth();

await recent.guard(() => account.changePassword({ currentPassword, newPassword })).catch(() => {});

{recent.needsReauth && (
  <PasswordPrompt
    onSubmit={(pw) => recent.reauthenticate(pw)} // re-runs the interrupted action on success
    onCancel={recent.cancel}
  />
)}
```

If the account has MFA, `reauthenticate` resolves with `{ retried: false, outcome }` where `outcome` is the MFA challenge; complete it, then call `guard` again.
